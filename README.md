# Relational SPD and the Toy Model of Geometry

A fork of [goodfire's SPD codebase](https://github.com/goodfire-ai/param-decomp) for our experiments on relational SPD, the toy model of geometry, and the effect larger ranks in SPD.

## Installation

Installation instructions are found within the `src` folder, in the official SPD README.

## Code Changes

The most relevant code changes can be found within `src/spd/models` and `src/spd/experiments`.

The rest of the code was minimally altered to make it compatible.
